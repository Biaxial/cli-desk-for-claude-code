# Contributing | 贡献指南

Contributions are welcome. Please open a focused pull request with a clear description of the change.

欢迎贡献。请提交范围清晰的 Pull Request，并说明变更内容。

1. Fork the repository and create a branch for your change.
2. Install dependencies with `npm ci`.
3. Run `npm test`; it must pass before submitting your pull request.
4. Keep credentials, API keys, personal data, local configuration, and private logs out of commits.
5. Preserve the project's unofficial third-party disclaimer in user-facing materials.

1. Fork 本仓库，并为你的改动创建独立分支。
2. 使用 `npm ci` 安装依赖。
3. 提交 Pull Request 前运行 `npm test`，并确保通过。
4. 不要在提交中加入凭据、API 密钥、个人数据、本地配置或私有日志。
5. 在面向用户的材料中保留项目的非官方第三方声明。
