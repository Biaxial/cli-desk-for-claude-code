# Security | 安全说明

Please report vulnerabilities privately through GitHub Security Advisories. On the repository's **Security** tab, select **Report a vulnerability**. Do not publish exploit details or sensitive data in an issue.

请通过 GitHub Security Advisories 私下报告安全漏洞：进入仓库的 **Security** 标签页并选择 **Report a vulnerability**。请勿在公开 Issue 中发布漏洞利用细节或敏感数据。
